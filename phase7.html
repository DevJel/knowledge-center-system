1. Description, Purpose and Boundaries

Scale only after measuring bottlenecks and service outcomes.

Treat phase 7: post-launch & scale as an independently reviewable capability. Trace its inputs, processing decisions and acceptance evidence before applying it to a live system. The examples define bounded units; external services need separately verified permissions, contracts and environment configuration.

2. Architectural Principles and Decisions

The primary decision boundary is: Optimize one bottleneck with representative traffic. Application logic and an accountable owner establish this decision. Preserve the input identity and rule revision so its outcome can be investigated.

Prioritize optimizing token price while increasing failures and unbounded concurrency overwhelms dependency. Establish checks for these failures before enabling automation. Completion requires evidence for the final step, canary and retain a rollback target, rather than merely observing request acceptance.

6. Implementation Pattern and Copyable Code

This focused TypeScript implementation belongs in the trusted application or test layer. Supply identity, permission and provider-verification state from real verified dependencies; do not accept trust flags directly from a browser.

typescript
export interface RunMetric {
  success: boolean;
  totalCost: number;
  elapsedMs: number;
}
export function summarize(runs: readonly RunMetric[]) {
  if (runs.length === 0) throw new Error("No measured runs");
  const successes = runs.filter(run => run.success).length;
  const sorted = runs.map(run => run.elapsedMs).sort((a, b) => a - b);
  const cost = runs.reduce((sum, run) => sum + run.totalCost, 0);
  return {
    count: runs.length,
    successRate: successes / runs.length,
    p95Ms: sorted[Math.ceil(sorted.length * 0.95) - 1],
    costPerSuccess: successes === 0 ? null : cost / successes
  };
}

Version the implementation with the consuming application and run this chapter’s acceptance checks when its assumptions change. A copied unit does not establish that all external integrations are active.

Treat llms by ai task as an independently reviewable capability. Trace its inputs, processing decisions and acceptance evidence before applying it to a live system. The examples define bounded units; external services need separately verified permissions, contracts and environment configuration.

2. Architectural Principles and Decisions

The primary decision boundary is: Compare representative quality, latency and cost. Application logic and an accountable owner establish this decision. Preserve the input identity and rule revision so its outcome can be investigated.

Prioritize unsupported structured-output option and cheaper model causes more expensive retries. Establish checks for these failures before enabling automation. Completion requires evidence for the final step, approve exact registry version with rollback, rather than merely observing request acceptance.

5. Detailed Mechanics and Topic Features

Reasoning and difficult coding

OpenAI GPT-6 Astra; Claude Fable 5.1 or Opus 5.5. Evaluate correctness on complex tasks, tool reliability and cost per successful completion.

Everyday coding and assistants

GPT-6.1 Sol; Claude Sonnet 5.5; Gemini 3.8 Flash. Compare repository tasks, editing quality, latency and regression rate.

High-volume extraction and routing

GPT-6 Luna; Claude Haiku 5.5; Gemini 3.5 Flash-Lite. Test schema validity, rare classes and escalation behavior before choosing the cheapest tier.

Visual reasoning and document interpretation

GPT-6.1 Terra; current vision-capable Claude or Gemini models. Evaluate document layout, small text and uncertainty; use OCR/layout tools where needed.

Deep multimodal reasoning

Gemini 4 Argon; evaluate other current vision-capable reasoning models. Use representative multimodal inputs; a large context window does not guarantee retrieval accuracy.

Retrieval embeddings

Gemini Embedding 2; appropriate embedding models in Workers AI. Embedding models create vectors, not answers. Match index dimensions and distance metric; changing models generally requires re-embedding.

Voice and transcription

Gemini 3.8 Live, Gemini 3.5 Transcribe; provider-specific realtime/STT models. Measure interruption handling, transcription accuracy, supported languages and end-to-end audio delay.

Image generation and editing

GPT-Image-2.5 family; Gemini Nano Banana family. Use dedicated image models for visual creation; compare edit preservation, text accuracy and rights requirements.

Edge and hosted open models

Cloudflare Workers AI catalog. Select an exact supported model identifier for text, embedding, reranking or speech. Verify plan, quota and runtime support; compatible endpoints do not imply identical features.

10. Operations, Ownership and Maintenance

Assign a technical owner for llms by ai task. Review changes to OpenAI catalog, Claude catalog, Gemini catalog against this chapter’s assumptions. Record the dependency contract, environment and last tested revision.

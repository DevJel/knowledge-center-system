# Feature, Design and Architecture Review

Reviewed 2 November 2026 — revision 2.1

## Changes

Restored full-chapter search with keyboard shortcut, result snippets and safe DOM rendering. Added chapter title filtering, static page outlines, previous/next navigation, mobile menu, skip link, reading progress, persistent theme, print rules and code wrapping. Improved code/chapter copy handling and clipboard fallback. Isolated Mermaid failures by diagram and preserved visible source.

The architecture now documents the actual static application. Four obsolete, unreferenced renderer/style assets are removed. All chapter content remains embedded directly in its HTML file.

## Completed verification

The Python structural validator passes all twenty-six HTML documents. It checks one h1 per page, main/article landmarks, active chapter, duplicate IDs, navigation targets, local anchors, assets and search index coverage. Enhancement JavaScript passes Node syntax checking. Publishing runs these checks before Pages upload.

## Limits

Browser appearance, focus behavior, clipboard permissions, external Mermaid loading and live HTTPS have not been verified by the structural checks. The presence of educational integration examples does not imply that external services are deployed.
